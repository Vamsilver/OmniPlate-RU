## 2. Спецификация архивов

### Архив №1: `OmniPlate-RU_solution.zip` (Код + Модели + Отчет)
*Предназначен для мгновенного развертывания жюри на тестовом стенде без интернета.*
- **Общий вес архива**: **< 20 МБ** (легковесный архив, помещается в форму любой тестирующей системы).
- **Состав архива**:
  * `run.py` — главный CLI-скрипт инференса (100% OFFLINE, совместим с авто-чекером);
  * `requirements.txt` — минимальные и достаточные зависимости окружения;
  * `README.md` — исчерпывающий RUNBOOK запуска в 1 команду;
  * `CONSTITUTION.md` — правила и гарантии безопасности ТЗ;
  * `models/` — все 3 рабочие ONNX-модели (суммарно 13.2 МБ):
    - `models/detector_yolo_pose.onnx` (12.1 МБ, детектор BBox + Quad);
    - `models/ocr_lprnet_best.onnx` (1.1 МБ, OCR LPRNet Conv-CTC);
    - `models/plate_verifier.onnx` (30.8 КБ, защитный гвард от Fatal Penalty);
  * `src/` — чистый модульный исходный код конвейера;
  * `tests/` — полный набор автоматических тестов (43/43 unit-теста);
  * `docs/report/EXPLANATORY_NOTE.md` — пояснительная записка (до 5 страниц);
  * `scripts/validate_dataset.py` — эталонный валидатор датасета;
  * `scripts/benchmark_latency.py`, `scripts/benchmark_full_dataset.py` — бенчмарки скорости и качества.
- **Исключаются из архива №1**: тяжелые исходные изображения, кэши `.venv`, `.pytest_cache`, `.git`, промежуточные чекпоинты `.pt`.

### Архив №2: `OmniPlate-RU_dataset.zip` (Датасет + Валидатор)
*Размещается в облачном хранилище (Яндекс.Диск / Cloud Mail / Google Drive).*
- **Объем данных**: 6 492 аннотации (5 000 синтетических + 1 492 реальных дорожных фото).
- **Состав архива**:
  * `dataset/images/real/` — 1 492 реальных изображения (лица 100% деидентифицированы YuNet);
  * `dataset/images/synthetic/` — 5 000 эталонных синтетических кадров;
  * `dataset/labels/` — файлы текстовых аннотаций YOLO-pose;
  * `dataset/meta.csv` — каталог метаданных по схеме ТЗ (10 колонок, открытые лицензии CC BY 4.0);
  * `dataset/generator/` — детерминированный процедурный генератор (seed=42);
  * `dataset/README.md` и `dataset/LICENSE` — DataSheet и открытая лицензия CC BY 4.0;
  * `scripts/validate_dataset.py` — официальный скрипт проверки;
  * `dataset_validation_report.txt` — отчет валидатора (100% PASS, 0 ошибок, 0 варнингов).

## 4. Автоматизированная сборка архивов

Для исключения человеческого фактора упаковка выполняется скриптом `scripts/package_submission.py`:

```bash
python scripts/package_submission.py
```

Скрипт автоматически:
1. Запускает тесты `pytest` и валидатор `validate_dataset.py`;
2. Формирует директорию `submission/`;
3. Архивирует код, модели и отчет в `submission/OmniPlate-RU_solution.zip`;
4. Генерирует `submission/SUBMISSION_MANIFEST.txt` с размерами и контрольными суммами SHA-256;
5. Выводит готовый текст сообщения для жюри Volga IT 2026.
