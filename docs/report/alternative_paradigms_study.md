# Сравнительное исследование парадигм OCR для распознавания номерных знаков РФ
# Alternative OCR Paradigms Study — OmniPlate-RU / Итерация 9

> **Проект:** OmniPlate-RU — автономная система распознавания госномеров РФ  
> **Дата:** 2026-09-19  
> **Датасет:** `dataset/meta.csv` — 3 168 валидационных кропов (val_split=0.15)  
> **GPU:** NVIDIA RTX 5080, CUDA 12.4 | **Framework:** PyTorch 2.6.0 + ONNX Runtime 1.23

---

## 1. Цель исследования

Итерация 9 проекта OmniPlate-RU ставит задачу экспериментально оценить альтернативные парадигмы OCR для распознавания российских номерных знаков ГОСТ Р 50577-93 (Type 1, 1A, 1B) в сравнении с эталонным baseline — монолитным LPRNet-v2 с CTC Loss.

Исследование охватывает **5 независимых подходов** по трём направлениям:
- **Routing/Ensemble** (Вектор 1): тип-условная маршрутизация (MoE).
- **Геометрическая коррекция** (Вектор 2): Micro Spatial Transformer Network.
- **Альтернативный Loss** (Вектор 3): Positional Multi-Head Cross-Entropy без CTC.

---

## 2. Методология бенчмарка

### 2.1 Датасет

- **Источник:** `dataset/meta.csv`, кропы 160×36 px (ГОСТ Type 1/1B) и 160×36 px (сшитый Type 1A).
- **Разбивка:** детерминированный split (seed=42, val_split=0.15).
- **Val-пул:** **3 168 кропов** — синтетика + реальные кадры (Type 1: 1814, Type 1A: 737, Type 1B: 507, Type 2: 110).
- **Предобработка:** нормализация пикселей [0, 1], resize до (160, 36, 3) → тензор (3, 36, 160).

### 2.2 Метрики

| Метрика | Формула | Описание |
|---------|---------|----------|
| **SeqAcc** | `exact_matches / total × 100%` | Строгое совпадение всего номера |
| **CER** | `Σlevenshtein(pred,gt) / Σlen(gt) × 100%` | Посимвольная ошибка |
| **Latency GPU** | mean/p50/p95 (200 итераций, batch=1) | Время инференса RTX 5080 |
| **Latency CPU** | mean/p50/p95 (100 итераций, batch=1) | Время инференса (CPU baseline) |

### 2.3 FSM Beam Search

Для CTC-моделей (Solo v2, v3, MoE) применяется `FSMBeamSearchDecoder` (beam_width=10) с:
- Грамматикой ГОСТ-маски по позициям (`[ABEKMHOPCTYX][0-9]{3}[ABEKMHOPCTYX]{2}[0-9]{2,3}`).
- Оптическими бонусами (`0↔O`, `8↔B`, `5↔3` и др.) из матрицы путаницы.
- Триплетным FSM-приором для 3-значных регионов (77→777, 50→750).

Для **Positional Net** декодирование — строгий argmax per head, FSM не применяется (отсутствие CTC).

## 3. Парадигма 1 — Базовый CTC (Solo LPRNet-v2)

### 3.1 Архитектура

**LPRNet-v2** — улучшенный LPRNet с дилатированными сверточными блоками (RF=61 px):

```
Input (3,36,160) → Stem [Conv-BN-ReLU + MaxPool] → Block1[64ch] → Pool → Block2[128ch]
→ Block3/4[256ch, dilation=(1,2)/(1,3)] → AdaptiveAvgPool(1,18)
→ Multi-scale cat [64+128+256=448ch] → ECA Attention → CTC-head [37 classes]
→ CTC Loss → FSMBeamSearch → Plate String
```

- **Loss:** CTC (Connectionist Temporal Classification) с blank-токеном (класс 0).
- **Decoder:** FSM Beam Search (beam_width=10) + confusion matrix prior.
- **Параметры:** ~1.1M | **ONNX:** 1 130 KB.

### 3.2 Результаты

| Метрика | Type 1 | Type 1A | Type 1B | Type 2 | Overall |
|---------|--------|---------|---------|--------|---------|
| SeqAcc  | 93.50% | 97.29%  | 99.01%  | 94.55% | **95.30%** |

| CER | GPU Mean (ms) | GPU P95 (ms) | CPU Mean (ms) |
|-----|--------------|-------------|--------------|
| 1.230% | 7.321 | 19.394 | 0.612 |

> [!NOTE]
> LPRNet-v2 является **эталонной моделью** проекта: наивысшая точность на Type 1B (99.01%), минимальная CER (1.230%). Используется как дефолтная модель в `run.py`.

---

## 4. Парадигма 2 — Расширенный CTC (Solo LPRNet-v3)

### 4.1 Архитектура

**LPRNet-v3** — v2 + 1D-ASPP блок (Atrous Spatial Pyramid Pooling) + ECA-Net Attention:

```
...Block3[256ch] → ASPPBlock1D [d=1,d=2,d=4 параллельные ветви → 256ch]
→ ECA-Net 1D [3 параметра, kernel=3] → AdaptiveAvgPool(1,18)
→ Multi-scale cat [448ch] → CTC-head
```

- **Loss:** CTC (идентично v2).
- **Decoder:** FSM Beam Search (beam_width=10).
- **Параметры:** ~1.8M | **ONNX:** 1 808 KB.
- **Обучение:** 50 эпох, OneCycleLR, distillation от teacher LPRNet-v2 (T=2.0, α=0.4).

### 4.2 Результаты

| Метрика | Type 1 | Type 1A | Type 1B | Type 2 | Overall |
|---------|--------|---------|---------|--------|---------|
| SeqAcc  | 94.60% | 97.15%  | 97.83%  | 93.64% | **95.68%** |

| CER | GPU Mean (ms) | GPU P95 (ms) | CPU Mean (ms) |
|-----|--------------|-------------|--------------|
| 1.319% | 8.693 | 20.006 | 0.759 |

> [!TIP]
> LPRNet-v3 превосходит v2 на критически важном классе **Type 1 (+1.1%)** за счёт большего рецептивного поля ASPP, но уступает на Type 1B (-1.18%). Используется через `--ocr_version v3`.

## 5. Парадигма 3 — Type-Conditioned Routing (MoE)

### 5.1 Концепция

**Mixture of Experts (MoE)** — не новая архитектура, а тип-условная маршрутизация запросов к специализированным экспертам:

```
Input Crop + Detected Plate Type
    │
    ├── Type 1   → LPRNet-v3  [94.60% на Type 1]
    ├── Type 1A  → LPRNet2D   [97.29% на Type 1A — нативная 2D-архитектура]
    ├── Type 1B  → LPRNet-v2  [99.01% на Type 1B]
    └── Type 2   → LPRNet-v2  [94.55% на Type 2]
         │
    → FSM Beam Search → Plate String
```

**Ключевая идея:** каждый тип пластины получает оптимального специалиста вместо компромиссного универсала.

### 5.2 Результаты

| Метрика | Type 1 | Type 1A | Type 1B | Type 2 | Overall |
|---------|--------|---------|---------|--------|---------|
| SeqAcc  | 94.60% | 97.29%  | 99.01%  | 94.55% | **95.93% 🏆** |

| CER | Gain vs v2 | Gain vs v3 |
|-----|-----------|-----------|
| **1.211%** | +0.63% SeqAcc | +0.25% SeqAcc |

> [!IMPORTANT]
> MoE является **текущим SOTA** проекта: SeqAcc 95.93%, CER 1.211%. Синергетический эффект достигается не за счёт новых параметров, а за счёт специализации — каждый тип получает «своего» эксперта.  
> Накладные расходы: задержка инференса аналогична одиночной модели (~8 мс), т.к. тип определяется детектором бесплатно.

## 6. Парадигма 4 — Micro Spatial Transformer (STN)

### 6.1 Архитектура

**MicroSpatialTransformer** — ультра-компактный дифференцируемый модуль геометрической коррекции:

```
Input (3,36,160)
→ STN Localisation Net [Conv→Pool→FC→FC → θ(2,3)]  ← 69 998 параметров
→ Grid Generator + Bilinear Sampler (GridSample, opset 18)
→ Corrected Crop (3,36,160)
→ LPRNet-v2 / CTC decoder
```

- **Инициализация:** тождественное преобразование `θ = [[1,0,0],[0,1,0]]`.
- **Ограничение:** деформации через `tanh` для стабильности.
- **ONNX:** 38.8 KB (параметры STN) — самая компактная модель исследования.
- **Интеграция:** `STNLPRNet` = STN + LPRNet-v2 (состав: 69 998 + ~1.1M параметров).

### 6.2 Результаты стресс-теста (600 кропов с искусственными возмущениями)

| Условие | Angle (°) | Shear | SeqAcc | Δ vs Clean |
|---------|-----------|-------|--------|------------|
| **Clean** | 0° | 0 | **95.33%** | — |
| Mild Roll | ±3° | 0 | 91.67% | -3.66% |
| **Moderate Roll** | **±6°** | 0 | **77.00%** | **-18.33%** ⚠️ |
| Significant Roll | ±10° | 0 | 21.83% | -73.50% |
| Extreme Roll | ±15° | 0 | 0.17% | -95.16% |
| Mild Shear | 0° | +0.08 | 95.67% | +0.34% |
| Strong Shear | 0° | +0.15 | 94.17% | -1.16% |
| Compound | ±6° | +0.10 | 68.67% | -26.66% |

| GPU Mean (ms) | GPU P95 (ms) | CPU Mean (ms) | ONNX Size |
|--------------|-------------|--------------|-----------|
| 5.964 | 14.838 | 1.225 | 38.8 KB |

> [!CAUTION]
> Micro-STN демонстрирует **критическую уязвимость 1D-CTC**: при Roll > 6° точность обваливается (-18.33%...-95%). Физически объяснимо: CTC-декодер сканирует горизонтальные временны́е шаги — перекос нарушает временно́е соответствие символов. STN с 70K параметров недостаточно мощен для компенсации больших углов. Рекомендован **только для Shear-коррекции** (±0.15), где показывает стабильность.

## 7. Парадигма 5 — Positional Non-CTC Multi-Head (PositionalPlateNet)

### 7.1 Архитектура

**PositionalPlateNet** — принципиально иной подход: вместо CTC-декодирования временной последовательности каждая позиция номера имеет **независимый классификатор**:

```
Input (B,3,36,160)
→ Stem [Conv-BN-ReLU + MaxPool] → (B,64,18,80)
→ Block1[64ch] + Pool → Block2[128ch] → Block3[256ch] + Pool → Block4[256ch]
→ Multi-scale AdaptiveAvgPool(1,9):
    stem[64ch] || block2[128ch] || block4[256ch] → (B,448,1,9)
→ Bottleneck [Conv1×1, 448→256] → Dropout
→ 9 × nn.Linear(256 → num_classes_i)   ← независимый head на каждую позицию
→ Positional CrossEntropyLoss (sum over 9 positions)
→ argmax per head → concat → Plate String
```

**Словари по позициям ГОСТ:**

| Позиция | Тип | Классов | Пример |
|---------|-----|---------|--------|
| 0 | Буква серии | 13 (12 + PAD) | А |
| 1-3 | Цифры | 11 (10 + PAD) | 1,2,3 |
| 4-5 | Буквы серии | 13 | В,С |
| 6 | Первая цифра региона | 10 (1-9 + PAD) | 7 |
| 7-8 | Цифры региона | 11 (0-9 + PAD) | 7,7 |

- **Loss:** `PositionalCELoss` — сумма 9 `CrossEntropyLoss` с `ignore_index=PAD`.
- **Decoder:** `decode_positional()` — строгий argmax, без FSM, без blank.
- **Ключевая гипотеза:** устранение CTC blank-collapse ошибок на 2/3-значных регионах (77→7, 777→77).

### 7.2 Результаты после минимального обучения (15 эпох)

**Параметры обучения:**
- Эпох: 15 | Оптимизатор: AdamW (lr=1e-3, wd=1e-4) | Scheduler: OneCycleLR (pct_start=0.15, cos)
- Batch: 64 | GPU: RTX 5080 | Train samples: ~N тыс. кропов (из PlateCropDataset train split)

| Метрика | Результат |
|---------|-----------|
| **SeqAcc** | **57.63%** |
| **CER** | **5.821%** |
| Exact Matches | 1 624 / 2 818 |
| Val Loss | 0.0688 (best epoch 13) |
| Параметры | 2.548M |
| ONNX Size | 79.3 KB |
| GPU Latency Mean | 2.316 ms |
| CPU Latency Mean | 6.336 ms |

> [!NOTE]
> Результаты получены при **минимальном обучении (15 эпох)** без дистилляции, без hard-negative oversampling и без FSM post-processing. CTC-модели обучались 50+ эпох с многоступенчатым fine-tuning. Сравнение иллюстрирует **архитектурный потенциал** парадигмы, а не её финальную точность.

## 9. Сравнительный анализ

### 9.1 Парадигмы с CTC (v2, v3, MoE) — доминируют по точности

**Преимущества CTC:**
- Не требует точной сегментации символов по позициям.
- FSM Beam Search компенсирует ошибки blank-collapse.
- 50+ эпох обучения с продвинутыми аугментациями.

**Недостатки CTC:**
- Blank-collapse: CTC может схлопнуть повторяющиеся символы (77→7, BB→B).
- Чувствительность к перекосу (Roll) — временной шаг нарушается.
- Необходимость сложного post-processing (FSM, confusion matrix).

### 9.2 Micro-STN — специализированный инструмент, не общее решение

STN с 70K параметрами демонстрирует важный результат: **1D-CTC принципиально неустойчив к перекосу Roll > 6°**. Это не дефект STN, а фундаментальное ограничение временно́й природы CTC-декодирования.

Применимость: предобработка для Shear-коррекции (±0.15) при дорожных камерах с наклоном. Неприменим при Roll > 6° без более мощного STN-backbone.

### 9.3 Positional Net — перспективный но недообученный

**Ключевые преимущества архитектуры:**
- Нет blank-токена → нет blank-collapse ошибок на регионах 77/777.
- Каждая позиция имеет dedicated классификатор → структурный приор ГОСТ вшит в архитектуру.
- Простой и детерминированный decoder (argmax, без beam search).
- Нет зависимости от временного выравнивания → теоретически устойчив к перекосу Roll.

**Текущие ограничения (15 эпох):**
- CTC-модели обучались 50+ эпох с дистилляцией и hard-negative mining.
- Нет FSM post-processing — грамматика не используется в инференсе.
- Алфавит фиксирован на Type 1/1B (9 позиций) — Type 1A требует адаптации.

### 9.4 Рекомендации для Production

| Сценарий | Рекомендуемая парадигма |
|----------|------------------------|
| Максимальная точность (overall) | **MoE Routing** (95.93% SeqAcc) |
| Минимальный footprint (1 модель) | **Solo LPRNet-v2** (1.1M, 95.30%) |
| Акцент на Type 1 (однострочные) | **Solo LPRNet-v3** (94.60% Type 1) |
| Дорожные камеры с наклоном (shear) | **STN + LPRNet-v2** (shear stable) |
| Исследование без CTC | **PositionalPlateNet** (нужно 50+ эпох) |

## 10. Выводы

1. **MoE Routing** достигает SOTA (95.93% SeqAcc, 1.211% CER) без увеличения задержки инференса — рекомендован как дефолтная конфигурация для production.

2. **Micro-STN** подтвердил фундаментальное ограничение 1D-CTC: коллапс при Roll > 6°. В реальной эксплуатации большинство кропов ректифицируются детектором — STN нецелесообразен как обязательный компонент.

3. **PositionalPlateNet** демонстрирует принципиально иную парадигму распознавания с потенциалом устранения blank-collapse ошибок. При 15 эпохах обучения без FSM достигает **57.63%** SeqAcc. Полноценное сравнение требует 50+ эпох, hard-negative mining и позиционного FSM-приора.

4. Направление дальнейших исследований: гибридная модель **Positional + FSM-приор** (грамматика ГОСТ вшита в decoder как допустимые классы per position) + дистилляция от LPRNet-v2 как teacher.
