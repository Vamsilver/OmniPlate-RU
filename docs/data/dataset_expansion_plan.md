## 1. Контекст и мотивация
По результатам валидации сквозного инференса (End-to-End) зафиксирована общая точность **96.12%** (471 / 490 совпадений).
Однако обнаружен дисбаланс классов в реальной выборке:
- **Type 1** (Однострочные легковые): 410 сцен (точность 96.1%)
- **Type 1B** (Желтые ГОСТ): 66 сцен (точность 100.0%)
- **Type 1A** (Квадратные 2-строчные JDM/USDM): **12 сцен** (точность 75.0%, узкое место репрезентативности)
- **Type 2** (Автомобильные прицепы): **2 сцены** (точность 100.0%, критический дефицит выборки)

## 2. Цели и этапы расширения
1. **Создание staging-зоны** (`dataset/candidates_review/`):
   - Изолированные поддиректории: `type1a/` и `type2/`.
   - Защита рабочего датасета от непроверенных данных до ручного подтверждения.
2. **Сбор пула разнородных кандидатов**:
   - Реальные кадры из открытых архивов (Wikimedia Commons, Roboflow, HuggingFace/Nomeroff) с размытием лиц через YuNet (`FaceBlurrer`).
   - Синтез фотореалистичных сцен через `PlateRenderer` с 3D-гомографией, реалистичными нишами (JDM bumper recess) и площадками для прицепов (trailer frame / mud flaps).
3. **Интерактивный аудит (`run_audit_server.py`)**:
   - Запуск веб-галереи на `http://localhost:8080` с параметром `--review-dir dataset/candidates_review`.
   - Инспекция каждого кадра пользователем с кнопками «ДА, ВЕРНО» / «НЕТ, ОШИБКА» и вводом Ground Truth.
   - Фиксация решений в `dataset/candidates_review/review_decisions.csv`.
4. **Импорт одобренных кандидатов** в рабочий датасет (`dataset/images/real/` и `dataset/meta.csv`).
