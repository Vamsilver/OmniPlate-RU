# 02. Протокол проверки датасета (Validation Protocol)

## 1. Назначение протокола

Датасет — отдельно оцениваемый компонент с высоким весом. Любая ошибка в именовании, битая ссылка на изображение, несоответствие количества строк в `meta.csv` или нарушение формата `quad` снижает баллы.

Перед формированием итогового архива датасет проверяется официальным валидатором организаторов `validate_dataset.py`, а также локальным тестом целостности.

---

## 2. Чек-лист проверок целостности

1. **Файловая структура**:
   - `dataset/images/real/` существует и содержит не менее требуемого количества файлов.
   - `dataset/images/synthetic/` содержит не менее 5000 файлов.
   - `dataset/labels/` содержит соответствующий `.txt` для каждого файла в `images/`.
   - `dataset/generator/generate_synthetic.py` присутствует и имеет воспроизводимый seed.
   - `dataset/README.md` (DataSheet) заполнен.
   - `dataset/LICENSE` содержит текст CC BY 4.0.
2. **Проверка `meta.csv`**:
   - Разделитель — строго `;`.
   - Каждая строка содержит ровно 10 столбцов:
     `image;plate_num;plate_type;bbox;quad;is_vehicle;is_synthetic;source;license;conditions`.
   - Путь `image` указывает на существующий файл.
   - `plate_num` соответствует маске (1 буква, 3 цифры, 2 буквы, 2-3 цифры региона), латиница верхнего регистра, допустим символ `#`.
   - `plate_type` строго из множества: `{'type1', 'type1a', 'type1b', 'other'}`.
   - `bbox` — ровно 4 целых числа: `x,y,w,h` ($x \ge 0, y \ge 0, w > 0, h > 0$).
   - `quad` — ровно 8 целых чисел: `x1,y1,x2,y2,x3,y3,x4,y4`, образующих выпуклый четырехугольник по часовой стрелке.
   - `is_vehicle` и `is_synthetic` — строго `0` или `1`.
   - `conditions` — валидный список тегов через запятую.
3. **Объемы выборки**:
   - Реальные `type1a`: $\ge 150$ изображений, $\ge 50$ уникальных `plate_num`.
   - Реальные `type1b`: $\ge 300$ изображений, $\ge 100$ уникальных `plate_num`.
   - Реальные `other`: $\ge 50$ изображений.
   - Синтетика: $\ge 5000$ изображений.
4. **Отсутствие картинок из отладочного набора**:
   - Сравнение SHA256-хэшей всех файлов датасета с хэшами 30 изображений из отладочного набора организаторов. Пересечений быть не должно!
