# 01. Источники реальных данных, лицензии и приватность

## 1. Правовые требования к датасету

Согласно регламенту полуфинала:
1. **Лицензия сдачи**: Сдаваемый датасет публикуется под открытой лицензией **Creative Commons Attribution 4.0 International (CC BY 4.0)**.
2. **Гарантия прав**: Участник гарантирует, что имеет юридическое право использовать все материалы и передавать их организаторам для последующей публикации объединенного датасета олимпиады.
3. **Запрещенные источники**: Запрещено использование материалов из закрытых систем, защищенных капчей/авторизацией сервисов, парсинг в нарушение условий использования (ToS) сайтов.

---

## 2. Легальные источники для сбора реальных данных

### 1. Собственная фото- и видеосъемка (`own_photo`)
- Съемка на парковках торговых центров, улицах города, кадры с личного видеорегистратора.
- **Статус лицензии**: Авторские права принадлежат участнику, передаются по CC BY 4.0.
- **Обозначение в `meta.csv`**: `source: own_photo`, `license: CC-BY-4.0`.

### 2. Открытые датасеты с лицензиями CC0 / CC BY / MIT / Apache 2.0
- **Roboflow Universe**: поиск датасетов с тегами `license-plate`, `russian-license-plate`, `taxi`, фильтрация по совместимой свободной лицензии.
- **Kaggle Datasets**: датасеты российских номеров (с обязательной верификацией лицензии в карточке датасета).
- **Wikimedia Commons**: фотографии автотранспорта под свободными лицензиями.
- **Open Images Dataset (Google)**: класс `Vehicle registration plate`.

## 3. Требование приватности: Анонимизация лиц

> [!IMPORTANT]
> **Обязательное требование регламента**:
> Лица людей на изображениях **должны быть размыты (Gaussian Blur) или закрыты черным/пиксельным прямоугольником**. Изображения, на которых человек является смысловым центром кадра, в датасет не включаются.

### Автоматический конвейер анонимизации:
Для исключения человеческого фактора при подготовке реальной части датасета применяется скрипт препроцессинга с легковесным детектором лиц (например, `YuNet` из OpenCV или `RetinaFace`):
1. Запуск детектора лиц на каждом кандидате в датасет.
2. Если обнаружено лицо:
   - Если площадь лица $> 15\%$ кадра $\to$ изображение отбраковывается (человек в центре кадра).
   - Если лицо фоновое/прохожий $\to$ применение `cv2.GaussianBlur` с радиусом размытия, гарантирующим невозможность деанонимизации.
3. Сохранение обработанного изображения в `dataset/images/real/`.
