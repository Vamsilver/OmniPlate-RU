# 📐 01. GOST R 50577-2018 Geometry & Rendering Specification

```yaml
# QUICK_CONSTANTS

CANONICAL_TYPE1_PX: [160, 36]   # W x H for OCR input
CANONICAL_TYPE1A_PX: [160, 96]  # W x H for Warp (Split: Top 160x48, Bot 160x48)
```

---

## 1. Type 1 (Тип 1: Однострочный белый)
- **Габариты**: $520 \times 112$ мм, радиус закругления углов $12$ мм.
- **Компоновка слева направо**:
  1. Первая буква серии (высота $58$ мм, ширина $34$ мм).
  2. Три цифры номера (высота $76$ мм, ширина $40$ мм).
  3. Две буквы серии (высота $58$ мм, ширина $34$ мм).
  4. Разделительная вертикальная линия.
  5. Код региона (2 или 3 цифры, высота $58$ мм).
  6. Надпись `RUS` (высота $14$ мм) + Флаг РФ ($17 \times 11$ мм: белый, синий, красный).

---

## 2. Type 1A (Тип 1А: Двухстрочный квадратный белый)
- **Габариты**: $290 \times 170$ мм.
- **Две строки**:
  - **Верхняя строка**: 1 буква серии (высота $45$ мм) + 3 цифры номера (высота $58$ мм).
  - **Нижняя строка**: 2 буквы серии (высота $45$ мм) + код региона (2-3 цифры, высота $45$ мм) + надпись `RUS` и Флаг РФ справа внизу.
- **Канонический кроп для OCR**:
  - Размер после гомографии: $160 \times 96$ px.
  - Разрез по вертикали: $y \in [0, 48]$ — верхняя строка; $y \in [48, 96]$ — нижняя строка.

---

## 3. Type 1B (Тип 1Б: Однострочный жёлтый)
- **Габариты**: $520 \times 112$ мм.
- **Цветовые координаты фона**:
  - HEX: `#FFCC00`
  - RGB: $(255, 204, 0)$
  - HSV: Hue $\in [20^\circ, 35^\circ]$, Saturation $\ge 180$, Value $\ge 180$.
- **Отличие от Типа 1**: Флаг РФ отсутствует, надпись `RUS` расположена в правом нижнем углу зоны региона.

---

## 4. Шрифтовая спецификация
- Шрифт строго по **ГОСТ Р 50577-93 / 50577-2018** (прямое полужирное начертание, фиксированная ширина штриха).
- Символы выдавлены (штамповка) с фаской $1.5$ мм, создающей характерные микротени.
