# Датащит датасета VolgaIT ГРЗ (License Plate Dataset)

## 1. Описание набора данных
Набор данных сформирован в рамках полуфинала олимпиады Volga IT 2026 (дисциплина «Искусственный интеллект и анализ данных», кейсодержатель: АИС Город).
Цель набора данных: обучение и валидация моделей детекции (BBox + 4 угла полигона `quad`) и оптического распознавания нестандартных государственных регистрационных знаков РФ (ГОСТ Р 50577-2018), в частности типов 1А (квадратные двухстрочные) и 1Б (желтые пассажирские).

## 3. Источники данных и методики сбора
- **Синтетика (5000 кадров)**: сгенерирована процедурным генератором `dataset/generator/generate_synthetic.py` с 3D-проекцией гомографии, металлическими градиентами, шумами и аугментациями.
- **Реальные уличные кадры (500 кадров)**: собраны из открытых репозиториев Wikimedia Commons под открытыми лицензиями CC BY / CC BY-SA с деперсонализацией.
- **Авторазметка и координаты**: полигоны 4 углов (`quad`) и BBox для реальных кадров получены через модель `detector_yolo_pose_best.pt` с ручной верификацией.

---

## 4. Защита персональных данных и этика
- Все лица людей на реальных фотографиях в обязательном порядке обработаны нейросетевым конвейером `dataset/privacy/face_blur.py` (OpenCV YuNet ONNX) с применением Gaussian Blur.
- Фотографии, в которых человек занимает доминирующую часть кадра (>15% площади), автоматически отбракованы.
