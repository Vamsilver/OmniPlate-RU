# Датащит датасета VolgaIT ГРЗ (License Plate Dataset)

## 1. Описание набора данных
Набор данных сформирован в рамках полуфинала олимпиады Volga IT 2026 (дисциплина «Искусственный интеллект и анализ данных», куратор: АИС Город).
Цель набора данных: обучение и валидация моделей детекции и оптического распознавания нестандартных государственных регистрационных знаков РФ (ГОСТ Р 50577-2018), в частности типов 1А (квадратные двухстрочные) и 1Б (желтые пассажирские).

---

## 2. Статистика выборки

| Категория | Подкатегория | Количество изображений | Количество уникальных ГРЗ |
|---|---|---|---|
| **Реальные** | `type1a` (квадратные) | 0 (в процессе сбора) | 0 |
| **Реальные** | `type1b` (желтые) | 0 (в процессе сбора) | 0 |
| **Реальные** | `other` (негативные) | 0 (в процессе сбора) | — |
| **Синтетические** | `type1`, `type1a`, `type1b` | 0 (в процессе генерации) | 0 |
| **ИТОГО** | | 0 | 0 |

---

## 3. Источники данных и методики сбора
- **Собственные фотоматериалы (`own_photo`)**: съёмка на парковках и дорогах общего пользования.
- **Открытые репозитории и датасеты**: материалы, распространяемые под лицензиями CC0, CC BY, MIT, Apache 2.0.
- **Синтетика**: сгенерирована с использованием процедурного генератора `dataset/generator/generate_synthetic.py` с фиксированным зерном псевдослучайных чисел (`seed`).

---

## 4. Защита персональных данных и этика
- Все лица людей на реальных фотографиях обработаны фильтром Gaussian Blur для гарантированной анонимизации.
- Фотографии, в которых человек является смысловым центром кадра, исключены из датасета.
