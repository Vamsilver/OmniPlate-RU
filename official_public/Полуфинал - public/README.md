# Волга-IT 2026, полуфинал, «ИИ и анализ данных» — служебные скрипты

| Файл | Кому | Зависимости | Назначение |
|---|---|---|---|
| `validate_dataset.py` | участникам и жюри | только stdlib (Python ≥ 3.9) | валидатор датасета по разделу 6; отчёт прикладывается к решению |
| `evaluate.py` | жюри | только stdlib | сопоставление CSV решения с эталоном, метрики, первичный балл (раздел 8, п. 3) |
| `generate_synthetic_plates.py` | пример / для отладочного набора | numpy, opencv, Pillow | генератор синтетики типов 1 / 1А / 1Б сразу в структуре датасета |

## validate_dataset.py

```
python validate_dataset.py dataset/                       # отчёт в консоль + validation_report.txt
python validate_dataset.py dataset/ --json report.json    # + полный список сообщений
python validate_dataset.py dataset/ --forbidden-hashes debug_hashes.txt   # проверка на отладочный набор
python validate_dataset.py --hash-dir debug_set/ > debug_hashes.txt      # (организаторам) md5 отладочного набора
```

Код возврата 0 — ошибок нет, 1 — есть ошибки, 2 — каталог не найден.

**ERROR** (сдача не допускается): нет обязательных каталогов/файлов, неверный заголовок или разделитель `meta.csv`,
файл из `meta.csv` не найден (в т.ч. не совпал регистр имени), `plate_num` не по маске типа, кириллица, код региона
`00`/`000` или трёхзначный не с 1/2/7, `plate_type` не из списка, `is_vehicle`/`is_synthetic` не 0/1 или не согласуются
с каталогом, пустые `source`/`license`, неизвестные `conditions`, `bbox` за границами кадра, `quad` за границами / вырожден /
против часовой / не с левого верхнего угла, нет `labels/<stem>.txt`, неразборчивые строки в labels, совпадение md5 с
отладочным набором.

**WARNING**: объёмы ниже рекомендованных (150/300/50 реальных, 5000 синтетики, 50/100 уникальных ГРЗ), лицензии
NC/ND/SA или нераспознанные, `bbox` не описывает `quad`, класс/bbox в labels не совпадает с `meta.csv`, побайтовые
дубликаты, изображения без строк в `meta.csv`, лишние файлы, слишком короткий README, генератор без `seed`.

Формат `labels/*.txt` принят YOLO-подобный: `class cx cy w h` (нормированные), опционально ещё 8 чисел — quad.
Классы: `0 type1, 1 type1a, 2 type1b, 3 other`. Если формат меток в задании будет другим — поправьте
`LABEL_CLASSES` и блок 6 в `validate()` или запускайте с `--labels-format none` (проверяется только наличие файлов).

## evaluate.py

```
python evaluate.py --gt reference.csv --pred result.csv --images test_images/ --json score.json --details details.csv
```

Сопоставление: на каждом изображении строки решения жадно привязываются к знакам эталона по посимвольному сходству
(порог 0.5). Позиции эталона с `#` не оцениваются; `#` в ответе решения — ошибка в позиции. Знак **засчитан**, если
совпали все читаемые позиции (при равной длине) **и** тип знака.

Первичный балл (веса меняются флагами `--w-type1 --w-type1a --w-type1b --w-precision`, `--max-score`):

```
A_t   = засчитанных знаков типа t / знаков типа t в эталоне
P     = засчитанных знаков / строк решения с plate_type ≠ other
Score = 0.15·A_type1 + 0.35·A_type1a + 0.35·A_type1b + 0.15·P
```

В `P` штрафуются лишние строки, строки для `other`/`is_vehicle=0` с типом ≠ `other`, дубли. Строки с `plate_type=other`
никогда не штрафуются — это штатный способ «отсеять». Если типа нет в тестовом наборе, его вес уходит в `P`.
Информационно выводятся recall, точность типа, посимвольная точность и средняя `confidence` у верных/ошибочных.

Кадры без знаков: перечислите их в эталоне строкой `img.jpg;;;` или передайте каталог через `--images` — иначе
ложные срабатывания на пустых кадрах не будут видны.

## generate_synthetic_plates.py

```
pip install numpy opencv-python-headless Pillow
python generate_synthetic_plates.py --count 5000 --out dataset --seed 42 [--font RoadNumbers.ttf] [--backgrounds photos/]
```

Пишет `images/synthetic/syn_*.jpg`, `labels/*.txt`, дописывает `meta.csv` (bbox, quad, conditions по фактически
применённым аугментациям). Один `--seed` → побайтово тот же набор. Основано на генераторе однострочных номеров из
рабочего пайплайна; добавлены двухстрочный 1А (290×170) и жёлтый 1Б (ЛЛ ЦЦЦ + регион), вклейка в кадр с перспективой
и до двух знаков на кадре.

## Что стоит поправить в тексте задания

1. **Маска типа 1Б.** В разделах 2 (абзац после таблицы), 4.2 и в примере раздела 5 (`K555OP25;type1b`) сказано,
   что состав символов у всех трёх типов одинаков. По ГОСТ Р 50577-2018 тип 1Б — `ЛЛ ЦЦЦ РР(Р)` (две буквы, три цифры,
   регион), например `AB12377`. Скрипты заложены под ГОСТ; в «Справочной информации» нужно дать вторую маску.
2. **Раздел 9 (метрики)** упоминается в 8.3, но в документе отсутствует — формула выше предлагается как его основа.
3. **Формат `labels/*.txt`** (6.2) не описан: нужно зафиксировать (предложен YOLO + опциональный quad и карта классов).
4. `<ссылка организаторов>` на `validate_dataset.py` (6.2) — плейсхолдер.
5. В 6.1 объёмы названы «рекомендуемыми», а в 6.2 валидатор «обязателен» — стоит явно сказать, что объёмы дают только
   предупреждения, а ошибки формата блокируют сдачу (так и реализовано).
