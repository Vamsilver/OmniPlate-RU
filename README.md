## 🎯 Цели и ключевые вызовы

1. **Проблема «длинного хвоста» (Long Tail)**:
   - Стандартные модели уверенно находят прямоугольные белые номера (`type1`), но слепы к **квадратным двухстрочным** (`type1a`) и **желтым пассажирским** (`type1b`).
   - Наша цель — собрать сбалансированный обучающий датасет и обучить ансамбль/пайплайн, не теряющий качество на обычном потоке.
2. **Строгий SLA по скорости (< 100 мс на изображение)**:
   - Проверка осуществляется на скромном стенде: **Intel Core i5-7600 + NVIDIA GTX 1050 Ti (4 ГБ VRAM)**.
   - Требуется оптимизация времени выполнения: квантование, FP16, ONNX Runtime / TensorRT.
3. **Строгая структура датасета**:
   - Датасет — самостоятельный оцениваемый артефакт.
   - Обязательный прогон через `validate_dataset.py` без единой ошибки.

├── README.md                   # Главный портал проекта (этот файл)
├── docs/                       # Разветвленная база знаний и спецификаций
│   ├── requirements/           # Требования олимпиады и регламент
│   ├── architecture/           # Архитектурные решения и спецификации моделей
│   ├── data/                   # Данные, лицензии, валидация

├── dataset/                    # Датасет по регламенту
│   ├── images/
│   │   ├── real/               # Реальные изображения
│   │   └── synthetic/          # Сгенерированные изображения
│   ├── labels/                 # YOLO/Quad текстовые аннотации
│   ├── meta.csv                # Каталог метаданных датасета
│   ├── generator/              # Воспроизводимый скрипт генерации синтетики
│   ├── README.md               # Датащит датасета
│   └── LICENSE                 # Лицензия CC BY 4.0
